# AI-Assisted Operations Study Helper

## Purpose
An educational demonstration for explaining introductory programming and technical documentation concepts.

## Architecture
Static HTML interface + CSS + JavaScript knowledge base. A question is lowercased, matched against topic keywords, and answered using a fixed explanatory response. No API calls or personal data collection.

## Testing
Test Java inheritance, arrays, exceptions, pump, documentation, empty input, unmatched questions, keyboard Enter, and Clear. Verify on mobile and desktop.

## Limitations
Only six topic groups; keyword matching may misclassify questions. Not a source of safety-critical or professional operating instructions.

## Improvements
Add unit tests, citations to course materials, more questions, and an optional genuine LLM integration with server-side API key management if approved.
